## 8. Parité tokenizer / gabarit : défaut d'outillage trouvé et corrigé

### 8.1 Défaut trouvé dans le script de parité

Le script `docs/audits/scripts/m11.1-chat-template-audit.py` à la révision `7d5685a` comparait :

```python
direct_ids = list(tok.apply_chat_template(msgs, return_tensors=None, tokenize=True, **kw))
```

`apply_chat_template(..., tokenize=True)` renvoie un **`BatchEncoding`**, qui hérite de `UserDict`
et **n'est pas** un `dict` : `list(objet)` itère sur les **clés** du dictionnaire. Les deux listes
comparées étaient donc `["input_ids", "attention_mask"]` (2 éléments) contre les 19–267 identifiants
du rendu : **les 9 cas positifs échouaient** (`ECHEC_INATTENDU`, code de sortie 1). Le contrôle
n'était pas tautologique, il était structurellement faux — et il se signalait lui-même, ce qui est
le comportement attendu d'une porte fail-closed.

Correctif appliqué dans le présent mandat (aucune autre modification du script) :

```python
direct = tok.apply_chat_template(msgs, return_tensors=None, tokenize=True, **kw)
direct_ids = list(direct["input_ids"] if "input_ids" in direct else direct)
if direct_ids and isinstance(direct_ids[0], list):
    direct_ids = direct_ids[0]
```
