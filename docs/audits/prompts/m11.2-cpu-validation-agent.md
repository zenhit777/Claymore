## Semantics to pay special attention to

- GDN recurrent state remains FP32 and invalid tokens do not commit state.
- Masking follows upstream multiplication semantics, including IEEE `NaN * 0 = NaN`.
- GDN block preview reads clean state only; it must not mutate it.
- Preview attention masks invalid keys but retains invalid query rows; commit attention masks invalid query rows and applies causality within the block.
- Right-context convolution must use validity-masked current-block values.
- BF16 output comparisons use the documented one-ULP bound; FP32 gate/state tolerances are recorded in the manifest.
- No implicit FP16 conversion or hidden dtype promotion is permitted.
