## Critères d'arrêt

Arrêter sans modifier les empreintes épinglées si :
- un SHA diffère ;
- un shard manque, un nom/shape/dtype ne correspond pas ;
- un sidecar n'est pas BF16 ;
- le plan contient un chunk supérieur à 8 MiB, un offset incohérent ou un ordre non déterministe ;
- la parité token IDs directe/rendu échoue ;
- le snapshot ne correspond pas à la révision épinglée ;
- une étape tente d'utiliser CUDA ou la VRAM.
